4. Ambiente e reprodutibilidade

Todo o laboratório roda em contêineres leves com Docker Compose, em um único computador, sem máquinas virtuais adicionais. No macOS o Docker Desktop executa os contêineres dentro de uma máquina virtual Linux própria; todos os contêineres compartilham o kernel e o relógio dessa máquina.

A zona sd.lab usa os valores do roteiro: TTL 60 s, serial inicial 2026101401, refresh 30 s, retry 10 s, expire 300 s e TTL negativo 20 s. Os secundários usam min-refresh-time 10 e min-retry-time 5 para que esses temporizadores curtos sejam aceitos.

Repositório e execução

Repositório Git: https://github.com/arthawreliuk/sistemas-distribuidos-m2-dns. Para reproduzir:

git clone https://github.com/arthawreliuk/sistemas-distribuidos-m2-dns.git && cd sistemas-distribuidos-m2-dns
docker compose build                # imagem sd-bind
./scripts/e1.sh                     # sobe o laboratório e grava evidências
./scripts/e2.sh ... ./scripts/e8.sh # um script por experimento
docker compose --profile e9 up -d   # CoreDNS e instâncias api1..api3
./scripts/e9.sh
docker compose --profile e9 down    # remove só o que é do projeto

Cada script registra a saída completa em evidencias/eN/ e os dados das medições em resultados/*.csv. A previsão de cada experimento está em evidencias/eN/PREVISAO.md, gravada no Git antes da execução.

Adaptações em relação aos trechos do roteiro

  • A chave do rndc é gerada na construção da imagem; sem ela, o rndc reload usado no roteiro não funciona.
  • O primário usa notify explicit com also-notify nos endereços internos, para que NOTIFY e transferências passem só pela rede interna, condição para o E6. Os secundários usam notify no.
  • O arquivo da zona é gravado de dentro do contêiner ns1 e cada rndc reload é conferido com uma consulta ao SOA. Na primeira execução do E2, um reload feito logo após gravar o arquivo pelo macOS não carregou a nova versão; o roteiro já alerta para conferir o serial após cada alteração.
  • coreutils na imagem, para medir tempo com frações de segundo (date +%s.%N).
